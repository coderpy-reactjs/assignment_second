# 📝 React To-Do App

A simple and clean to-do list app built with **React**. Add tasks, mark them as completed, and dynamically manage your list – all with an attractive UI and smooth UX.

---

## 🚀 Features

- ✅ Add new to-do tasks
- 🚫 Alert if the task input is empty
- 🧾 Display a dynamic list of tasks
- 📦 Mark tasks as complete using a checkbox
- ✨ Simple, attractive, and responsive design

## 🛠️ How to Run the Project

### 1. Prerequisites

Make sure you have **Node.js** and **npm** installed. You can check with:

```bash
    node - v
    npm  - v
```
2. Create and Set Up the App
If you haven’t already created the React app:
```bash
    npx create-react-app todo-app
    cd todo-app
```

3. Replace Source Files
Replace the default code in:
```bash
    src/App.js
    src/App.css
    src/index.js
```


With your custom To-Do app code.

4. Start the Development Server
   ``` bash
   npm start

Your app should open automatically in your browser at:
```bash 
  http://localhost:3000
```
